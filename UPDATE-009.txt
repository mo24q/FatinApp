فطين — إصلاح قاعدة البيانات 009

1. في مشروع Supabase المرتبط بموقعك افتح SQL Editor ثم New query.
2. شغّل كامل supabase/migrations/009_foundation_repair.sql.
   الملف المنفصل fatin-database-repair-009.sql مطابق له؛ استخدم واحدًا فقط.
3. بعد نجاحه حدّث صفحة فطين وأنشئ غرفة جديدة.

لا تحتاج إعادة رفع الموقع أو تغيير المفاتيح. رفع SQL إلى GitHub لا يطبقه على Supabase.
لا تشغّل 001 من جديد ولا تعِد 002 أو 003 منفردين فوق الإصدار الحالي.
الإصلاح يحافظ على الغرف والمحتوى الموجود ويمكن تكراره.

يمكن رفع محتويات fatin-database-repair-update.zip إلى جذر GitHub لحفظ الملف والتعليمات.
التفاصيل: docs/DATABASE-REPAIR.md
هذا الإصلاح اختُبر محليًا؛ يجب تشغيله في Supabase قبل إعادة فحص الأونلاين مباشرة.
