فطين — مراجعة أفالون ٢ نوفمبر ٢٠٢٦

سبب عطل إنشاء غرفة الأونلاين: لم يشغّل تحديث 010 في Supabase.
افتح Supabase → SQL Editor → New query، الصق كامل fatin-avalon-010.sql ثم Run.
إذا ظهر FATIN_RUN_009_FIRST، شغّل تحديث 009 أولًا ثم 010. لا تعِد تشغيل 001.
لا تحتاج تغيير المفاتيح أو إعدادات Vercel لهذا العطل.

هذه الحزمة تصحح عرض عدد الفريقين قبل اكتمال خمسة لاعبين وتضيف اختبارات وتوثيق المراجعة.
فك الضغط وارفع محتوياته إلى جذر مستودع GitHub مع استبدال الملفات المطابقة، دون حذف باقي المشروع.
الحزمة تحديث تكميلي لنسخة أفالون الحالية وليست مشروعًا مستقلًا.
لا تحتوي تحديثًا جديدًا لقاعدة البيانات؛ استخدم ملف 010 الذي سُلّم سابقًا.

التحقق: نجح 97 اختبارًا، منها 15 لأفالون، و3 سيناريوهات متصفح لأفالون، وبناء الإنتاج وTypeScript.
الموقع المنشور توقف عند غياب دالة أفالون. يبقى التحقق الفعلي بعد تشغيل 010.
