# سجل التحقق — ١٨ أكتوبر ٢٠٢٦

## تم التحقق

| الفحص | النتيجة |
|---|---|
| `npm install` | تم تثبيت الحزم وتثبيتها في `package-lock.json`؛ فحص npm وقت التثبيت لم يسجل ثغرات معروفة. |
| `npm test` | ١٧ اختبارًا ناجحًا على PGlite 0.3.16، تنفيذًا لملف SQL نفسه. |
| `npm run build` | بناء إنتاج ناجح على Next.js 16.4.2، مع فحص TypeScript وتوليد الصفحات. |
| طلب HTTP للرئيسية | استجابة 200 من خادم Next.js المحلي. |
| متصفح سطح المكتب | فحص بصري للرئيسية وقائمة الألعاب. لا رسائل خطأ/تحذير في سجل المتصفح عند الفحص. |
| عرض ٣٩٠ و٣٢٠ بكسل | فحص الواجهة العربية وعدم وجود تمرير أفقي بعد إصلاح الحد الأدنى لعرض شبكة المقدمة. |
| نافذتا إنشاء/انضمام | التركيز ينتقل إلى الاسم، إغلاق النافذة يعمل، اختيار مدة النقاش ظاهر، والرمز يُحوّل إلى أحرف كبيرة. |
| عدم وجود إعدادات Supabase | إنشاء الغرفة معطّل مع رسالة واضحة؛ رابط غرفة مباشر يوضح الحاجة للإعداد. |

إصدارات بيئة التحقق: Node.js 24.16.0، React 19.3.1، TypeScript 5.9.3، Tailwind 4.3.3، Supabase JS 2.118.0.

## تغطية اختبارات قاعدة البيانات

1. رمز قصير، إنشاء وانضمام، وهوية ثابتة عند العودة.
2. رفض مفتاح `anon` بلا جلسة ورفض هوية JWT الفارغة.
3. الاسم، مدة النقاش، والحد الأدنى للاعبين.
4. الاسم المكرر، الانضمام المتأخر، وإعادة الاتصال خلال الجولة.
5. لاعب واحد برا السالفة، كلمة موحدة للبقية، وغياب الأسرار عن استجابة الحالة.
6. منع غير الأعضاء من الحالة والدور وأوامر اللعب حتى مع معرفة الرمز.
7. صلاحيات المضيف، حاجز جاهزية الجميع، ورفض رقم الجولة القديم.
8. صوت واحد نهائي، منع التصويت للنفس أو للاعب خارجي، وخصوصية الاختيارات.
9. حسم فوز المجموعة وكشف النتيجة بعد اكتمال الأصوات.
10. التعادل، غياب الأصوات، وحسم المهلة من قراءة عضو.
11. كلمة ودور مختلفان في الإعادة، وعدم وصول صوت قديم لجولة جديدة.
12. الحضور، منع البدء مع غائب، ونقل الاستضافة بعد دقيقة.
13. إلغاء الجولة دون كشف الأسرار، وإزالة العضوية بين الجولات فقط.
14. RLS لإشعارات Realtime، ومنع قراءة كل الجداول والدوال السرية مباشرة.
15. الحد ١٢ لاعبًا، انتهاء صلاحية الغرفة، والتنظيف.
16. المغادرة ونقل الاستضافة وسحب صلاحية العضو السابق.
17. حصة إنشاء الغرف تبقى نافذة بعد مغادرة/حذف الغرف، وتجدد بعد ساعة.

## لم يُتحقق بعد

لا توجد بيانات مشروع Supabase أو Vercel في البيئة؛ لذلك لم يُنشأ نشر خارجي ولم تُختبر دورة لعب من عدة جوالات عبر Auth وRealtime الحقيقيين، ولا تكامل Turnstile الفعلي. مراحل الغرفة اختُبرت على مستوى قاعدة البيانات؛ الفحص البصري للمتصفح شمل الرئيسية والنماذج وحالة الإعداد الناقص فقط.

PGlite يشغّل PostgreSQL داخل عملية الاختبار مع `auth.uid()` محاكى؛ لا يختبر توقيع JWT لدى GoTrue، أو خدمة Realtime، أو بيئة تحميل متزامن حقيقية. أقفال صف الغرفة مفروضة في SQL، لكن اختبار ضغط على PostgreSQL المستضاف مطلوب قبل توسيع الاستخدام.

خادم التطوير المحلي مؤقت. أعد تشغيل `npm run dev` عند الحاجة. اتبع قائمة القبول في README بعد وضع المفاتيح وتطبيق الترحيل، ثم اختبر الرابط المنشور على ثلاثة أجهزة مستقلة.
