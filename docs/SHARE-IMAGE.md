# مشاركة البطاقات كصورة

المشاركة الآن ملف PNG فقط، دون رابط أو نص مرفق. الصورة تعرض اسم اللاعب وبطاقاته الثماني برسوماتها: الأسلحة يمينًا والأدلة يسارًا. لا تتضمن الدور أو حل القضية.

يُجهَّز الملف قبل ضغط زر المشاركة لدعم مشاركة الملفات على الجوال. عند عدم الدعم يبدأ التنزيل وتظهر الصورة للحفظ يدويًا. لا توجد حزم أو مفاتيح أو خطوات SQL جديدة.

فك ضغط fatin-share-image-update.zip وارفع محتوياته إلى جذر FatinApp بنفس المجلدات، ثم احفظ التغييرات وانتظر نشر Vercel. الحزمة تتضمن تعديل إزالة التلميحات السابق.

لم تُشغّل اختبارات أو بناء لهذا التعديل حسب طلب المستخدم.
