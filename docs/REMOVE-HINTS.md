# تحديث واجهة الجريمة المغلقة

أزيل قسم «خيوط القضية» كاملًا، واختيارات التلميحات من مساحة الراوي، والنصوص المرتبطة بها في تعليمات اللعب والأدوار. التعديل يشمل الجوال الواحد والأونلاين.

فك ضغط fatin-remove-hints.zip وارفع محتوياته بنفس المجلدات إلى جذر FatinApp، ثم احفظ التغييرات وانتظر نشر Vercel. لا يحتاج هذا التعديل تشغيل SQL أو تغيير المفاتيح.

لم تُشغّل اختبارات أو بناء لهذا التعديل، حسب طلب المستخدم. بقيت حقول قاعدة البيانات القديمة للتوافق مع الغرف والإصدارات السابقة؛ الواجهة لا تعرضها ولا ترسل أوامر تعديلها.
