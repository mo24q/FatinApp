# تحديث فطين: المؤقت والجوال الواحد

## لموقعك الحالي

1. افتح مشروع Supabase الذي يستخدمه فطين، ثم SQL Editor → New query.
2. انسخ كامل `supabase/migrations/002_host_timer.sql` وشغّله. لا تعِد تشغيل `001_lamma.sql`؛ قاعدة بياناتك موجودة أصلًا.
3. ارفع محتويات حزمة التحديث إلى مستودع FatinApp نفسه مع الاحتفاظ بالمجلدات. الملف الجديد `page.tsx` مكانه `src/app/local/page.tsx`؛ لا تنقله إلى جذر المستودع. لا تحذف ملفات المستودع أو تاريخه.
4. انتظر نشر Vercel الجديد إلى Ready. استخدم إعدادات Next.js ومفاتيح Supabase الحالية؛ لا يحتاج التحديث أي مفتاح جديد أو خطة مدفوعة.
5. حدّث الموقع في كل الأجهزة. اختر «نلعب مع فطين» ثم طريقة اللعب.

ملف 002 يضيف أعمدة ودوال ضمن معاملة واحدة، ولا يحذف غرفًا أو لاعبين أو كلمات أو أصواتًا. يمكن إعادة تشغيله عند الحاجة. إذا حدث خطأ داخل المعاملة تتراجع تغييراتها؛ أرسل نص الخطأ ولا تحذف الجداول لإصلاحه.

للتثبيت على مشروع جديد فقط: شغّل 001 أولًا، ثم 002. يمكن تطبيق 002 قبل نشر الواجهة؛ أوامر اللعب السابقة ما زالت مدعومة. يُفضّل التحديث بين الجلسات، ثم تحديث صفحات اللاعبين، لأن الواجهات القديمة لا تعرض حالة إيقاف المؤقت.

## المؤقت

- في اللوبي وشاشة الأدوار والنتيجة: المضيف يغيّر مدة النقاش أو يختار اللعب بدون مؤقت.
- أثناء النقاش والتصويت: تشغيل، إلغاء المؤقت، إيقاف مؤقت، استئناف، إعادة الوقت، وتطبيق مدة ١٥–٩٠٠ ثانية.
- تطبيق المدة يستبدل الوقت المتبقي بالمدة الجديدة ويحافظ على الإيقاف المؤقت. إلغاء المؤقت يجعل النقاش والتصويت بلا مهلة، ويستمر الاختيار للجولة التالية حتى يعيد المضيف تشغيله.
- انتهاء النقاش لا ينقل للتصويت تلقائيًا. التصويت ينتهي باكتمال الأصوات، أو انتهاء مؤقته الفعّال. المؤقت المتوقف مؤقتًا لا يمنع استقبال الأصوات.
- لا يمكن إحياء تصويت انتهى وقته بتغيير المدة؛ النتيجة تُحسم أولًا. إلغاء المؤقت مختلف عن إلغاء الجولة.
- تغيير المدة أو إيقاف المؤقت مسموح للمضيف الحالي فقط، مع تحقق رقم الجولة والمرحلة على السيرفر. تحكم المؤقت لا يعطي المضيف أسرار الآخرين.

## جوال واحد

- مسار `/local` يعمل بدون Supabase أو تسجيل دخول: ٣–١٢ اسمًا مختلفًا، ثم تمرير الجهاز بالتسلسل.
- لكل لاعب شاشة تسليم وزر لإظهار دوره، ثم زر لإخفائه والانتقال. يختفي الدور تلقائيًا بعد ١٢ ثانية أو عند مغادرة الشاشة.
- مؤقت النقاش قابل للتحكم. التصويت المحلي بلا مؤقت حتى يأخذ كل لاعب وقته في استلام الجوال، ويُخفى الصوت بعد تأكيده.
- بعد آخر صوت تظهر شاشة انتظار؛ زر مستقل يكشف النتيجة أمام الجميع. الجولة التالية بكلمة ودور مختلفين.
- الجلسة محفوظة في `sessionStorage` لهذا التبويب فقط، وصلاحية الاستعادة ٢٤ ساعة. التحديث يستعيد المرحلة مع إخفاء الدور؛ إغلاق التبويب قد ينهيها. إنهاء الجلسة يمسح بياناتها المحفوظة.
- لا يحتاج اللعب المحلي طلبات شبكة بعد تحميل الصفحة. ليس تطبيقًا مثبّتًا للعمل دون إنترنت: تحميل الصفحة أو إعادة تحميلها قد يحتاج اتصالًا.
- الخصوصية في الجوال الواحد تعتمد على تمرير الجهاز بحسن نية. مالك الجهاز أو من يفتح أدوات المطور يمكنه قراءة بيانات الجلسة. الغرف المنفصلة تحتفظ بحماية الأدوار على السيرفر.

## اختبار سريع بعد الرفع

1. افتح «جوال واحد»، أضف ثلاثة أسماء، وجرّب الأدوار والنقاش والتصويت والنتيجة وجولة ثانية.
2. حدّث الصفحة أثناء عرض دور؛ يجب أن ترجع شاشة التسليم دون إظهار الدور تلقائيًا.
3. افتح غرفة عادية بثلاثة أجهزة، وأوقف المؤقت واستأنفه من المضيف. تأكد من تطابق حالته عند الجميع وعدم ظهور أدواته لغير المضيف.
4. جرّب إلغاء المؤقت أثناء التصويت؛ يبقى قبول الأصوات متاحًا، وتظهر النتيجة عند اكتمالها.
