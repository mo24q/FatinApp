# تحديث مشروع فطين المرتبط بـVercel

لمن يستخدم نسخة فطين الحالية بالفعل: اتبع [تحديث 008](READINESS.md). بقية هذا الدليل لتأسيس الانتقال الأول من الموقع القديم.

المستودع: https://github.com/mo24q/FatinApp

صفحة المستودع العامة تعرض `main` فرعًا افتراضيًا، وتشير إلى https://fatin-app.vercel.app. لم تُفحص لوحة Vercel، لذلك يجب التحقق من Production Branch وإعدادات البناء هناك. هذه الحزمة هي الكود الجديد بالكامل؛ لم تُستخدم ملفات اللعبة القديمة أو بنك كلماتها.

## تحديث المصدر

1. أنشئ فرعًا جديدًا من `main` مثل `fatin-nextjs` في المستودع الحالي، واحتفظ بسجل Git القديم.
2. ضع محتويات حزمة فطين الجديدة في جذر ذلك الفرع، بحيث يكون `package.json` في الجذر.
3. استبدل ملفات الموقع القديمة في الفرع الجديد. لا تخلط ملفات HTML/JS القديمة مع التطبيق الجديد. لا تنقل `node_modules` أو `.next` أو `.env.local`؛ ملفات التجاهل مرفقة.
4. افتح Pull Request إلى `main`. افحص Vercel Preview قبل دمجه، وتحقق من إعدادات ربط Git إذا لم يُنشأ نشر معاينة تلقائيًا.

## تحديث إعدادات Vercel الحالية

استخدم مشروع Vercel المرتبط بالمستودع نفسه، وراجع:

| الإعداد | القيمة لهذه النسخة |
|---|---|
| Framework Preset | Next.js |
| Root Directory | جذر المستودع، إذا وضعت `package.json` فيه |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | الافتراضي لـNext.js؛ أزل أي تجاوز مخصص للموقع القديم |
| Node.js | 24.x |
| Production Branch | تحقق من الفرع المرتبط؛ الفرع الافتراضي العام حاليًا `main` |

أضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` إلى بيئتي Preview وProduction، وطبّق ملف SQL وفعّل دخول الضيوف كما في README. إذا كان لديك Supabase قديم ببيانات مهمة، استخدم مشروعًا جديدًا لهذه النسخة أو راجع تعارضات المخطط قبل تطبيق الترحيل؛ لا تضع ملف التهيئة فوق جداول موجودة عشوائيًا.

بعد نجاح المعاينة وتجربة ثلاثة لاعبين، ادمج التحديث إلى فرع الإنتاج. ربط Git المفعّل سيؤدي إلى نشر التحديث وفق إعدادات مشروعك. لا يلزم تغيير النطاق الحالي.

## حالة هذه الحزمة

تغيّر اسم التطبيق في الشعار والعنوان وبيانات الصفحة ورسالة الدعوة إلى «فطين». كلمة «لمّة» ما زالت تظهر في بعض الجمل بصفتها كلمة عربية للجَمعة، وليست اسم العلامة. بقيت أسماء التخزين الداخلية وملف الترحيل ثابتة لتجنب تغيير جلسات أو مراجع قائمة بسبب تغيير الاسم فقط.

لم تُرفع هذه الحزمة إلى GitHub ولم يُعدّل نشر Vercel من داخل هذه المحادثة. يلزم اتصال GitHub بصلاحية التحديث لإتمام الرفع هنا.
