# حدود الثقة

هذا القسم يصف **اللعب بالغرف**. وضع الجوال الواحد له حدود ثقة مختلفة موضحة في نهاية الملف.

## العميل غير موثوق

يمكن لأي لاعب تعديل JavaScript، استدعاء RPC يدويًا، وقراءة بيانات متصفحه. لذلك كل قواعد اللعبة مفروضة داخل `public.game_action`، والمستخدم يُستخرج من JWT عبر `auth.uid()`؛ لا يقبل التطبيق `user_id` أو `is_host` من الطلب. قيمة `p_target` تستعمل لاختيار تصويت/إزالة فقط، ولا تستطيع اختيار صاحب الدور المقروء.

## الأسرار

الكلمات المختارة وهوية «برا السالفة» والأصوات في مخطط `private`. صلاحيات المخطط والجداول والدوال الداخلية منزوعة من `PUBLIC` و`anon` و`authenticated`، مع RLS دون سياسات وصول مباشرة. الدوال العامة تملك `SECURITY DEFINER` و`search_path=''` وتستخدم أسماء جداول مؤهلة دون SQL ديناميكي.

`state` يعيد عرضًا عامًا للغرفة، مع صوت صاحب الجلسة وحده. لا يعيد أي دور أو كلمة قبل النتيجة. `role` يعيد دور المستدعي فقط، ويعيد كلمة `null` للاعب «برا السالفة». المضيف ليس استثناءً. بعد النتيجة تصبح الكلمة والهوية وأعداد الأصوات معلنة لأعضاء الغرفة.

لا توضع الأدوار في HTML الخادم، أو Next.js cache، أو localStorage، أو Realtime. جلسة Auth فقط محفوظة في المتصفح؛ حفظها معيار Supabase المعتاد. تصل الكلمة إلى ذاكرة متصفح اللاعب المخول عند طلبه لها، ويمكنه حفظها أو تصويرها. الإخفاء بعد ١٢ ثانية لا يمحو معرفته أو استجابة الشبكة، ولا يستطيع الموقع منع مشاركة الشاشة أو تواطؤ اللاعبين.

## التحديثات الفورية

`room_events(room_id, revision)` فقط ضمن Realtime. سياسة SELECT تتحقق من العضوية الحالية وصلاحية الغرفة. حتى لو ظهرت إشارة قديمة في طريقها أثناء إزالة عضو، فهي لا تحمل أسرارًا؛ RPC لاحق يفشل بعد إزالة العضوية. القراءة الدورية تعالج فقد الرسائل وانقطاع WebSocket.

## انتقالات اللعبة

قفل صف الغرفة `FOR UPDATE` يجعل الانتقالات والتصويت متسلسلة ضمن معاملات قاعدة البيانات. رقم الجولة مطلوب للأوامر المرتبطة بجولة لمنع وصول تصويت قديم إلى جولة جديدة. الأصوات فريدة لكل لاعب/جولة، ولا يسمح بتغيير الصوت أو التصويت للنفس أو لشخص خارج الجولة. لا تقبل العضوية الجديدة أثناء الجولة.

المؤقت يستند إلى وقت PostgreSQL. مؤقت المتصفح للعرض فقط. الوصول لمرحلة النتيجة بعد المهلة يتم في أول طلب صحيح من عضو، دون اعتماد على مؤقت Vercel أو بقاء المضيف متصلًا.

## الحدود

- رمز الغرفة دعوة للانضمام وليس سرًا لدور اللعب. من يعرفه يستطيع الانضمام في اللوبي أو بعد النتيجة ضمن الحد ١٢؛ لا يوجد PIN إضافي أو قائمة سماح أو حظر دائم في هذه النسخة.
- المضيف يستطيع إلغاء الجولة وإزالة لاعب بين الجولات، لكنه لا يستطيع اختيار «برا السالفة» أو الكلمة أو قراءة دور غيره.
- حصة الإنشاء: ٥ غرف ناجحة/ساعة لكل هوية ضيف، و١٠ غرف نشطة للعضوية الواحدة. الحصة مستقلة عن المغادرة. هذه ليست حماية شاملة من هجمات موزعة؛ حماية إنشاء الهويات في Supabase وCAPTCHA مهمة للموقع العام.
- `service_role` ومالك قاعدة البيانات قادران بطبيعتهما على قراءة الأسرار. لا توجد هذه المفاتيح داخل المشروع أو Vercel، ولا يجب مشاركتها مع اللاعبين.
- جلسات الضيف غير قابلة للاستعادة بعد حذف تخزين المتصفح. لا تستخدم نفس ملف تعريف المتصفح لاختبار لاعبين مستقلين.
- فحص SQL المحلي يثبت منطق الصلاحيات ضمن نموذج Auth المحاكى. يجب اختبار مفاتيح مشروعك وخدمة Auth وRealtime بعد الربط، خصوصًا قبل توسيع الاستخدام.

الاختبارات في `tests/game.test.mjs` تحاول استدعاء أوامر من غير أعضاء، تجاوز صلاحيات المضيف، الوصول المباشر للأسرار، تزوير هدف `role`، وتعديل جدول الإشعارات، وتتوقع الرفض.

## التحكم بالمؤقت

ترحيل 002 يبقي دوال الإصدار الأول داخل مخطط private دون صلاحيات تنفيذ للعملاء، ويضيف طبقة تحقق لأوامر `timer_*`. التحقق يشمل هوية العضو والمضيف الحالي ورقم الجولة والمرحلة، مع قفل صف الغرفة. كل المواعيد تستند إلى PostgreSQL؛ لا يمكن لعميل تعديل deadline مباشرة. لا يمكن تمديد تصويت انتهى بالفعل. أثناء الإيقاف المؤقت أو إلغاء المؤقت يكون deadline فارغًا؛ اكتمال الأصوات ما زال يحسم النتيجة. الإصدار الجديد متوافق مع أوامر الإصدار السابق، لكن يجب تحديث واجهات اللاعبين لرؤية حالة الساعة الجديدة.

## الجوال الواحد

`/local` لا يستعمل Supabase ولا جلسة Auth. كامل حالة الجولة محفوظ في `sessionStorage` لهذا التبويب، بما فيها الكلمة واللاعب المختلف والأصوات. هذه ليست عزلة أمنية بين اللاعبين؛ من يتحكم بالجهاز وأدوات المطور يستطيع قراءتها. حماية هذا الوضع عملية: شاشة تسليم، إظهار مقصود للدور، إخفاء تلقائي عند الانتقال والخلفية وبعد ١٢ ثانية، وعدم إظهار اختيارات الآخرين في واجهة التصويت. حالة إظهار الدور لا تُحفظ ولا تُستعاد عند التحديث.

البيانات المحلية تنتهي عند إنهاء الجلسة أو بعد ٢٤ ساعة عند محاولة الاستعادة، ويمكن فقدها بإغلاق التبويب. الجلسة المحلية ليست متزامنة بين أجهزة مختلفة. بنك الكلمات المحلي عام ولا يُستخدم كمصدر لكشف كلمة غرفة على السيرفر. قواعد أسرار الغرف وRLS لم تتغير.
